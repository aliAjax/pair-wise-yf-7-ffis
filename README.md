# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 矩形剪贴板

- 按住 **Shift** 在版面上拖过格子形成矩形选区，选区栏提供「复制 / 剪切 / 取消选区」。
- 复制或剪切后自动进入粘贴瞄准：移动鼠标可预览落点，点击格子以左上角落点粘贴；绿色为可放置，红色表示越界或目标格子已被占用。
- 粘贴前逐格检查，**任一冲突整次拒绝**，版面不发生任何变化。复制内容可重复粘贴。
- 剪切后源版面保持不变，仅当粘贴成功才清空原区域；「撤销最近一次剪切」可把最近一次剪切清掉的字恢复回原位（仅一次，恢复后即失效，冲突时同样整次拒绝）。
- 换纸或载入草稿会清空选区与瞄准态，剪贴板内容仍保留（剪切态会降级为复制，避免坐标失效）。
- 剪贴板内容写入浏览器 localStorage，刷新页面后仍可继续粘贴；按 **Esc** 可取消选区或退出瞄准。
