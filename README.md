# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 矩形剪贴板

- 按住 **Shift** 在版面格子上拖出矩形选区（蓝框）；Esc 或普通落字会取消选区。
- 「复制选区」/「剪切选区」，或 `Ctrl+C` / `Ctrl+X`。
- 点「粘贴」或按 `Ctrl+V` 进入粘贴模式：移动鼠标选择落点，绿色为可行预览，红色表示越界或占用；**任一格冲突则整次拒绝，源版面保持不变**。
- 剪切不会立刻清空版面，只有粘贴成功后才腾空原区域；剪切原区域在粘贴检查中视为将腾空，允许原地落贴。
- 成功的剪切粘贴可点「撤销剪切」（或 `Ctrl+Z`）恢复，仅保留最近一次剪切记录。
- 换纸、清空版面、载入草稿会清空选区；剪贴板内容与待剪切状态安全降级为普通复制，仍然保留。
- 选区、剪贴板、剪切快照都写入浏览器 localStorage，刷新页面后剪贴板仍可使用。

`node test/clipboard.test.js` 可运行剪贴板逻辑的端到端校验（基于内置最小 DOM shim，无外部依赖）。
